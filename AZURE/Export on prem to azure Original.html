Export DB from Azure to On-Premise SQL Server.

Now if you want to export already exist Azure SQL DB to Local SQL Server then connect Azure server,

GOTO >Select Required DB Properties > Task > Export Data-tier application
 

Provide path to save bacpac file > Next
 

Check summary
 
Export completed.
 

Now connect to Local SQL Server, Right Click Database folder > Import Data-tier Application
 
Next >
 

Browse already saved exported bacpac file from Azure server.
 

Connect to Local Server > Provide New DB Name > Select Path location to save Data (.mdf ) & log (.ldf) file > Next
 

Check Summary
 

Import Completed Successfully.
