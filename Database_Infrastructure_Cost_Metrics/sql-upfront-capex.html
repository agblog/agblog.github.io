⚠️ Critical Licensing Compliance Constraint

Under official Microsoft volume licensing guidelines, secondary database nodes are only granted complimentary status when remaining completely passive. Because this architecture explicitly leverages db2 as an active, readable secondary instance to process heavy reporting workloads, both engine replicas must be licensed for core software layers.
