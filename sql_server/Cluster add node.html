Following are steps to add new disk to cluster:


Add Cluster Disk


1) Add cluster disk 3 in disk  > click on Storage >then  disk >Right top Corner Add Disk click on that > then pop up window is open ADD DISK TO CLUSTER > Check box the cluster disk 3 > then click on ok button .


 Available Storage

2) Cluster disk 3 is add in Disk which is assigned to Available Storage

3) Right Click on Cluster disk 3 > click on MORE ACTION >then  click on Assign to another role > then POP UP window will open select SQL SERVER (MS SQL SERVER) >Then click on OK Button.


4) After Assign resources to Role  in DISK > Cluster Disk 3 assigned to SQL SERVER (MS SQL SERVER ) will display 

Dependencies


5) To add Cluster disk 3 Dependencies to SQL SERVER ROLE .
Click on Roles > SQL Server (MS SQL SERVER) > Resources >OTHER Resources right Click on properties > Click on DEPENDENCIES >ADD  AND /OR column select AND  and in Resources Column Select Cluster Disk 3 > Click on Apply then OK .
