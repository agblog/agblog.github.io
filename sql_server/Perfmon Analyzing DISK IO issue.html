Following are steps for analyzing perfmon data for IO latency:

Disk Queue Length:

Tracks the number of requests that are queued and waiting for a disk during the sample interval, as well as requests in service. As a result, this might overstate activity. If more than two requests are continuously waiting on a single-disk system, the disk might be a bottleneck.

PhysicalDisk:Avg. Disk Queue Length

This counter shows you the average number of read and write requests that were queued on the selected physical disk. It requires attention if this value frequently exceeds a value of 2 during peak usage of SQL Server.
