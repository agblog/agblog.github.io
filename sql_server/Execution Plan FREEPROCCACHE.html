Remove all elements from the plan cache for the entire instance. DBCC FREEPROCCACHE command allows you to clear the plan cache or a specific plan.

DBCC FREEPROCCACHE;
It can actually be pretty useful for resetting the cached_time time for sys.dm_exec_procedure_stats -- Remove all elements from the plan cache for one database
