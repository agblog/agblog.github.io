How to run sql server in single user mode
Before you begin
1. You cannot restore SQL databases that are in use. By placing SQL databases to be restored in single-user mode, you can avoid system attempts to restore those databases.
2. The Microsoft Management Console (MMC) cannot connect to a SQL Server instance that is started in single-user mode.
