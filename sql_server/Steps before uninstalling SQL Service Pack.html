Starting with service packs (Service Pack 1) in SQL Server 2008 you can uninstall them from Add/Remove Programs like any other update?

Before uninstalling SP take following actions:

We can easily downgrade by uninstalling service packs or cumulative updates.

First, we go the Control Panel as below.

In the screen that follows, we click on Programs and Features.

Click on View installed updates as below.

In the screen that appears, we click on the cumulative update or service pack we want to uninstall and click uninstall.



The process is essentially the same as Installation.
