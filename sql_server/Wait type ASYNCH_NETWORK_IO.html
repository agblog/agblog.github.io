ASYNCH_NETWORK_IO:
In SQL Server, ASYNC_NETWORK_IO wait time can be high due to slow network, like when the database is in the cloud and the application is on premise. 
ASYNCH_NETWORK_IO happens, too, it usually means someone is trying to pull a lot of data and their program isn't reading it from SQL Server fast enough, so SQL Server has to wait.  Usually this only impacts the individual, though sometimes it can also cause blocks for others.
The first scenario is that the session (i.e., SPID) is waiting for the client application to process the result set and send a signal back to SQL Server that it is ready to process more data. The second is that there may be a network performance issue.
