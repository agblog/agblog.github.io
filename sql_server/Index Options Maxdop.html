Index Option:
Maxdop:
With MAXDOP indexing hint, you can now control the number of processors / CPUâ€™s that can be used for performing index operations.
The MAXDOP index option overrides the max degree of parallelism configuration option only for the query specifying this option.

MAXDOP hint supports three values when used with any indexing operations:
  • MAXDOP = 0 This is the default server level setting. This instructs SQL Server to grant CPUâ€™s based on the available resources and server load.
  • MAXDOP = 1 This value disables use of parallelism and enables the operations to execute serially.
  • MAXDOP = 2 through 64 This value indicates SQL Server to use the number of CPUâ€™s specified in the value to process index operations.

Parallel index execution and the MAXDOP index option apply to the following Transact-SQL statements:
  1. CREATE INDEX
  2. ALTER INDEX REBUILD
  3. DROP INDEX (This applies to clustered indexes only.)
  4. ALTER TABLE ADD (index) CONSTRAINT
  5. ALTER TABLE DROP (clustered index) CONSTRAINT
The MAXDOP index option cannot be specified in the ALTER INDEX REORGANIZE statement.

Syntax:
ALTER INDEX index_name ON Tablename  
REBUILD WITH (MAXDOP=8);   
GO
