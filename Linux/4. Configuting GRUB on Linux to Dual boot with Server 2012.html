After configuring we get both Linux and Windows Loader



Start centos by entering your securables.

Login to root user to perform changes
Click on username not listed and login as root.
Or login as current user then change to root user
#su - root














First step is to find which partition of windows is bootable.
Type:- fdisk -l
In the Boot column the asterisk(*) mark shows it is boot partition and /dev/sda2 location.

Now get UUID of bootable partition by uaing following
#blkid
 Now at this location /dev/sda2 location note down the UUID.
And open the boot configuration file
#vim /etc/grub.d/41_custom
If you are not familiar with vim then use following command to open file in notepad
#gedit /etc/grub.d/41_custom

Add following entry as marked in rectangle area, just replace with your UUID










Check out the entries are added in file by showing last 10 lines
#tail -10 

grub2-mkconfig will generate a new configuration.
#grub2-mkconfig -o /boot/grub2/grub. cfg

Now take reboot and we see windows bootloader is up.
The second and third entries are for recovery in case of any failure.


After login to windows we see that there are only two drives. 

in Disk Management, the space given to linux are showing free space, dont format this drive or system wont boot.

This drive is not accessible by windows while you can access windows boot drive in Linux.
