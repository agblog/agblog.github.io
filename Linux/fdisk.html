But, the system would create it as sda5. This happens because of, after the partition are deleted, sda7 partition had been moved as sda4 and free space shift to the end.
To fix such partition order problems, and assign sda4 to the newly created partition, issue the â€˜xâ€˜ to enter an extra functionality section and then enter â€˜fâ€˜ expert command to fix the order of partition table as shown below.

         sectors (command 'u').

Syncing disks.
After, running â€˜fâ€˜ command, donâ€™t forget to run â€˜wâ€˜ command to save and exit from fdisk command mode. Once it fixed partition table order, you will no longer get error messages.
