🚀 Chapter 5: Always On Feature Activation, AG Provisioning & DB Sync

This chapter outlines how to activate high availability engine settings, create secure certificates, and establish a clusterless replication channel.

📋 Sequence 1 to 100: Activate HADR Extensions & Generate Primary Certs

001. Run these commands on both servers to turn on high availability framework extensions and restart the instance process daemon:

sudo /opt/mssql/bin/mssql-conf set hadr.hadrenabled 1
sudo systemctl restart mssql-server

# Verify that configurations updated inside the settings configuration file
cat /var/opt/mssql/mssql.conf

002. Connect to your client query tool on the Primary Server (rhel-node1) and build your security transport certificate along with port 5022 data listeners:

USE master;
GO
CREATE MASTER KEY ENCRYPTION BY PASSWORD = 'SecureKeyPassword99!';
GO

CREATE CERTIFICATE AG_Transport_Cert
WITH SUBJECT = 'Availability Group Replica Transport Authentication',
START_DATE = '2026-01-01', EXPIRY_DATE = '2035-01-01';
GO

CREATE ENDPOINT [Hadr_endpoint]
    STATE = STARTED
    AS TCP (LISTENER_PORT = 5022)
    FOR DATABASE_MIRRORING (ROLE = ALL, AUTHENTICATION = CERTIFICATE AG_Transport_Cert, ENCRYPTION = REQUIRED ALGORITHM AES);
GO

003. Export the certificate files out to your backup path so they can be securely shared with the replica server node:

BACKUP CERTIFICATE AG_Transport_Cert
TO FILE = '/var/opt/mssql/backup/agcerts/AG_Transport_Cert.cer'
WITH PRIVATE KEY (FILE = '/var/opt/mssql/backup/agcerts/AG_Transport_Cert.key', ENCRYPTION BY PASSWORD = 'SecureKeyPassword99!');
GO

📋 Sequence 101 to 200: Key Sharing, Secondary Imports & Seeding

101. Run this network copy command on the Primary Host console to move keys to the secondary host, then adjust file owner attributes:

sudo scp /var/opt/mssql/backup/agcerts/AG_Transport_Cert.* root@192.168.20.12:/var/opt/mssql/backup/agcerts/

# Switch to Server Node 2 and align access control lists permissions
sudo chown -R mssql:mssql /var/opt/mssql/backup/agcerts/
sudo chmod 600 /var/opt/mssql/backup/agcerts/AG_Transport_Cert.*

102. Connect to the Secondary Server (rhel-node2) query terminal to import the primary certificate keys and initialize the database endpoints:

USE master;
GO
CREATE MASTER KEY ENCRYPTION BY PASSWORD = 'SecureKeyPassword99!';
GO
CREATE CERTIFICATE AG_Transport_Cert FROM FILE = '/var/opt/mssql/backup/agcerts/AG_Transport_Cert.cer'
WITH PRIVATE KEY (FILE = '/var/opt/mssql/backup/agcerts/AG_Transport_Cert.key', DECRYPTION BY PASSWORD = 'SecureKeyPassword99!');
GO
CREATE ENDPOINT [Hadr_endpoint] STATE = STARTED AS TCP (LISTENER_PORT = 5022)
    FOR DATABASE_MIRRORING (ROLE = ALL, AUTHENTICATION = CERTIFICATE AG_Transport_Cert, ENCRYPTION = REQUIRED ALGORITHM AES);
GO

103. Create the clusterless Availability Group object by running this script on the Primary Server (rhel-node1):

CREATE AVAILABILITY GROUP [ptag] WITH (CLUSTER_TYPE = NONE) -- Set to NONE for clusterless architecture
FOR REPLICA ON
    N'rhel-node1' WITH (ENDPOINT_URL = N'TCP://192.168.20.11:5022', AVAILABILITY_MODE = SYNCHRONOUS_COMMIT, FAILOVER_MODE = MANUAL, SEEDING_MODE = AUTOMATIC, SECONDARY_ROLE(ALLOW_CONNECTIONS = ALL)),
    N'rhel-node2' WITH (ENDPOINT_URL = N'TCP://192.168.20.12:5022', AVAILABILITY_MODE = SYNCHRONOUS_COMMIT, FAILOVER_MODE = MANUAL, SEEDING_MODE = AUTOMATIC, SECONDARY_ROLE(ALLOW_CONNECTIONS = ALL));
GO

104. Connect to your query session on the Secondary Server (rhel-node2) and run this query block to join the pipeline and authorize automatic seeding:

ALTER AVAILABILITY GROUP [ptag] JOIN WITH (CLUSTER_TYPE = NONE);
GO
ALTER AVAILABILITY GROUP [ptag] GRANT CREATE ANY DATABASE;
GO

105. Finally, add your active production database containers to the group by running this script on the Primary Server (rhel-node1):

CREATE DATABASE EnterpriseAppDB;
GO
ALTER DATABASE EnterpriseAppDB SET RECOVERY FULL; -- Mandatory logging setting for Always On
GO

BACKUP DATABASE EnterpriseAppDB TO DISK = '/var/opt/mssql/backup/EnterpriseAppDB.bak' WITH COMPRESSION, STATS = 30;
BACKUP LOG EnterpriseAppDB TO DISK = '/var/opt/mssql/backup/EnterpriseAppDB.trn' WITH COMPRESSION, STATS = 30;
GO

ALTER AVAILABILITY GROUP [ptag] ADD DATABASE [EnterpriseAppDB];
GO
