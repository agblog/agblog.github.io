📦 Chapter 4: SQL Server 2025 Installation

This chapter walks you through installing the core database binaries and initializing your system administration accounts.

📋 Sequence 1 to 100: Register Package Repositories

⚠️ OS Library Dependency Warning: The database engine context tracking frameworks depend on features introduced in RHEL 9.7/9.8. Running older 9.4 staging releases will cause errors due to missing package dependencies.

001. Run these update steps on both servers to pull down the newest operating system patches and verify that you have at least 10 GB of free space inside the root partition:

sudo dnf clean all
sudo dnf update -y
cat /etc/redhat-release
df -h /opt

📷 [Visual Validation: Console display verification checks showing operating system release maps and disk free storage thresholds]

002. Register the official Microsoft package distribution channels across both staging server hosts:

sudo curl -o /etc/yum.repos.d/mssql-server.repo https://microsoft.com
sudo curl -o /etc/yum.repos.d/mssql-release.repo https://microsoft.com

003. Download and install the SQL Server core package along with its matching SELinux security module context extension:

sudo dnf install -y mssql-server mssql-server-selinux

📋 Sequence 101 to 200: Initialize the Database Instance

101. Run the initial configuration utility script to pick your licensing edition and establish passwords:

sudo /opt/mssql/bin/mssql-conf setup

➡️ Select option 2 (Enterprise Developer Edition - Free for non-production environments) and set a strong password for your core sa administrative user.

102. Turn on the background SQL Server Agent feature and bind utility connection tool paths to your system profile settings:

# Enable the automation engine properties
sudo /opt/mssql/bin/mssql-conf set sqlagent.enabled true

# Append command shortcuts to your terminal path variables
echo 'export PATH="$PATH:/opt/mssql-tools18/bin"' >> ~/.bashrc
source ~/.bashrc

103. Configure the system process daemon to load automatically on boot up, and test connection lines to confirm engine availability:

sudo systemctl enable mssql-server
sudo systemctl restart mssql-server

# Query local instance name to confirm connectivity
sqlcmd -S localhost -U sa -C -Q "SELECT @@SERVERNAME;"
