📦 Chapter 4: SQL Server 2025 Installation steps

This chapter registers the official distribution channels and sets up the instance binaries on the servers.

Step 4.1 & 4.2: Run Updates and Verify Free Disk Space

⚠️ Notice: The database security module relies on updates introduced in RHEL 9.8. Running older operating system versions may cause installation bugs.

Run these clean updates and confirm you have at least 10 GB of free space inside the /opt directory layout:

sudo dnf clean all
sudo dnf update -y
cat /etc/redhat-release
df -h /opt

Step 4.3 & 4.4: Register Repositories and Download Binaries

Add the official Microsoft package distribution channels to your repository definitions and run the installation:

# Download repository map setups
sudo curl -o /etc/yum.repos.d/mssql-server.repo https://microsoft.com
sudo curl -o /etc/yum.repos.d/mssql-release.repo https://microsoft.com

# Download the engine package along with context security extensions
sudo dnf install -y mssql-server mssql-server-selinux

Step 4.5 & 4.6: Run Instance Configuration Prompt Wizards

Execute the core configuration utility script to select your edition profile and assign passwords:

sudo /opt/mssql/bin/mssql-conf setup

➡️ Select option 2 (Enterprise Developer Edition) and set a strong, complex password for your main sa account.

Enable background service orchestration management tracking flags, update shell environment variable profiles, and launch the engine process daemon:

# Enable the SQL Server Agent feature
sudo /opt/mssql/bin/mssql-conf set sqlagent.enabled true

# Add command line tools to your profile path shortcuts
echo 'export PATH="$PATH:/opt/mssql-tools18/bin"' >> ~/.bashrc
source ~/.bashrc

# Start the main engine process automatically on boot up
sudo systemctl enable mssql-server
sudo systemctl restart mssql-server
