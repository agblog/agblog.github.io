🛠️ Chapter 2: Hostname Allocation & OS Firewall Setup

Run these initial setup commands to configure server names, map system networks, and open the network firewalls.

Step 2.1: Lock in Server Names

Run this command on your respective servers to set their network identification tags permanently:

# Run on Node 1
sudo hostnamectl set-hostname rhel-node1

# Run on Node 2
sudo hostnamectl set-hostname rhel-node2

Step 2.2: Add Local Server Mappings

Open the network mapping file on both servers using your text editor:

sudo vi /etc/hosts

Add these lines at the bottom of the text block so the servers know where to find each other:

192.168.20.11 rhel-node1
192.168.20.12 rhel-node2

Step 2.3: Open Networking Firewall Ports

💡 Note: Since this layout handles replication directly inside the SQL database engine (clusterless), standard cluster manager background daemon ports are omitted by design here.

Execute these commands on both servers to open the listener paths:

# Open standard port 1433 for database user connections
sudo firewall-cmd --permanent --add-port=1433/tcp

# Open mirroring port 5022 for Availability Group replication traffic
sudo firewall-cmd --permanent --add-port=5022/tcp

# Reload firewall policies to save changes immediately
sudo firewall-cmd --reload

# Install connection validation tools
sudo dnf install -y telnet nc

Step 2.4: Test Your Network Connections

Run these verification commands across hosts to guarantee network lines are open and clean:

# 1. Verification Ping checks
ping -c 3 192.168.20.11
ping -c 3 192.168.20.12

# 2. Port Validation (Run from Server 2 targeting Server 1)
telnet 192.168.20.11 1433
telnet 192.168.20.11 5022

# 3. Port Validation (Run from Server 1 targeting Server 2)
telnet 192.168.20.12 1433
telnet 192.168.20.12 5022
