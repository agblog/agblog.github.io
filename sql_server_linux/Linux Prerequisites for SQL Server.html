📋 Linux Prerequisites for SQL Server

This reference guide outlines the vital step-by-step prerequisite roadmap required to properly prepare your hardware, install the base operating system, register your software license entitlements, and avoid common package blockages during a SQL Server installation on Linux.

📐 Virtual Drive Configuration & Partition Requirements

When partitioning a new drive (such as a standard 500 GB storage block), observe these strict layout best practices during the Linux installation wizard phase:

  • Disk Partition Style: Ensure your storage layouts are configured using the Standard Partition model rather than dynamic styles.
  • Reclaiming Clean Storage: If you are working on a disk with lingering data blocks, make sure to back up vital items, select the **Reclaim Space** wizard function, and wipe old partitions entirely to ensure a clean install environment.
  • The 185 GB Architecture Splitting Strategy: For structured multi-boot configurations or modular testing, assign a clean total footprint of approximately **185 GB** to handle your system directories. Carve out standard independent partition tracks for the following core filesystems:
    • /boot (Kernel bootstrap files)
    • swap (System virtual memory paging partition)
    • /home (User account profiles directory tree)
    • / (The Root system directory block)
  • Leftover Capacity Insulation: Following this mapping framework leaves the remaining space (approximately 281 GB out of a 500 GB disk) unallocated, keeping it safely available as isolated buffer space for dual-boot configurations or additional database expansion drives.

🖥️ Baseline Engine Hardware Requirements

Your prepared virtual server node must meet or exceed these physical limits to load and sustain the database engine process daemon:

Resource Constraint Minimum Threshold Operational Performance Notes
System Memory (RAM) 2 GB Minimum Required to start the service engine and handle internal memory threads. Always account for this baseline when tracking resource limits.
File System Compatibility XFS or EXT4 Only SQL Server is fully optimized for these formats. Unvalidated file structures (like BTRFS) are entirely unsupported.
Available Disk Space 6 GB Free Space Ensures sufficient space for the core database binaries and application files under the /opt/mssql tree.
Processor Speed 2 GHz Clock Speed Guarantees reliable transaction throughput and calculation processing speeds.
Processor Cores 2 Physical Cores Required to manage concurrent database processes and multi-threaded tracking loops.
CPU Type x64-Compatible Architecture Optimized for 64-bit AMD and Intel processor sets. Emulation tools are not supported for production.

🔑 Registration with Red Hat Subscription Manager

❌ Critical Package Dependency Error: If your RHEL environment is not actively linked to your customer account entitlements, executing standard terminal installation utilities will trigger immediate breakage alerts such as: "Dependencies Error: As Subscription is necessary to install packages on RHEL."

To avoid repository lockouts, log into the newly deployed server as the **root user** and complete these registration steps before installing database tools:

1. Run the registration flag inside the console and provide your Red Hat customer portal access credentials:

# Activate your server using your personal Red Hat account credentials
sudo subscription-manager register --username your_username --password your_password

2. Check the subscription tool status overview logs to guarantee your entitlements show as attached and active:

sudo subscription-manager status

📦 System Component Package Matrix

Once you are online and registered, the official Microsoft software repositories break features into modular packages to keep your database environment clean and lightweight:

  • mssql-server: The foundational database engine container binaries and system schemas package.
  • mssql-server-agent: Unlocks automation features, execution alerting properties, and background maintenance scheduling.
  • mssql-server-fts: Adds linguistically-aware indexing and text pattern queries via Full-Text Search.
  • mssql-server-ha: Provides high availability clustering integration hooks and Always On data transport loops.
  • mssql-server-is: Enables execution of Integration Services (SSIS) data migration and ETL pipelines.

🛡️ Operational Best Practices & Account Security

  • Non-Root Hardening: Never run regular queries or script execution utilities under the absolute root administrative profile. Always provision an independent systems administrator group login to handle daily database tasks.
