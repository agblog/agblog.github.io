🛠️ Chapter 2: OS Environment Setup & Security Firewall Rules

This chapter guides you through standardizing system locales, aligning network time logs across subnets, and configuring secure firewall openings.

📋 Sequence 1 to 100: Host Base Alignment & Mappings

Perform these steps to prepare the local operating system environments across all three database host endpoints.

📁 Reference Source File: 1_Prerequisites.txt

001. Log into your server terminals and run these commands on all cluster members (DB1, DB2, and DR-DB1) to synchronize time tracking and environment variables:

# Update package mappings and pull system time syncing utilities
sudo apt-get update
sudo apt-get install -y chrony locales

# Standardize system locale settings to avoid translation runtime breaks
sudo locale-gen en_US.UTF-8
sudo update-locale LANG=en_US.UTF-8

002. Open your local static network routing files using a text editor on every node:

sudo vi /etc/hosts

003. Add these static mapping records to ensure host lookup paths remain clear even during local DNS drops:

192.168.1.1 DB1
192.168.1.2 DB2
172.30.1.1 DR-DB1
20.20.20.178 QDEVICE-SERVER

📋 Sequence 101 to 200: Firewall Rules & Multi-Subnet Security

Configure network security boundaries to protect cluster state changes and database mirroring pipelines.

📁 Reference Source File: 2_Firewall_Setup.txt

101. Run these UFW firewall commands on your main datacenter nodes (DB1 and DB2) to allow trusted multi-subnet inter-cluster data streams:

# Allow standard database application traffic on port 1433
sudo ufw allow proto tcp from 192.168.1.0/24 to any port 1433
sudo ufw allow proto tcp from 172.30.1.0/24 to any port 1433

# Open port 5022 for the database engine Always On mirroring endpoint data stream
sudo ufw allow proto tcp from 192.168.1.0/24 to any port 5022
sudo ufw allow proto tcp from 172.30.1.0/24 to any port 5022

102. Open clustering ports on all cluster members so Pacemaker and Corosync can exchange token messages and connect to the external QDevice Net Voter:

# Open port 2224 for PCS cluster management communication
sudo ufw allow proto tcp to any port 2224

# Open port 5405 over UDP for Corosync multicast cluster tokens
sudo ufw allow proto udp to any port 5405

# Open port 5403 for the external dynamic QDevice Net Voter daemon
sudo ufw allow proto tcp to any port 5403

103. Enable the security policies immediately to reload the active kernel tracking lists:

sudo ufw reload
sudo ufw status verbose
