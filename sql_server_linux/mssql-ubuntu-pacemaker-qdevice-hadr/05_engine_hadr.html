🚀 Chapter 5: SQL Server Engine Installation & Always On Setup

This chapter guides you through installing the database binaries, initializing instance security keys, and connecting replicas to the data mirroring pipeline.

📋 Sequence 1 to 100: Install SQL Engine & Activate HADR Extensions

Register the package repositories, download the base database systems, and enable high availability extensions inside the core configurations file.

📁 Reference Source Files: 6_Install_SQL_Server.txt | 7_Install_SQLCMD_Tools.txt | 8_Enable_AlwaysOn_AG.txt

001. Run these installation lines on all cluster hosts to register the Microsoft package repositories and pull the database server binaries:

# Add the official Microsoft package distribution keys
sudo curl -sSL https://microsoft.com | sudo gpg --dearmor -o /usr/share/keyrings/microsoft-prod.gpg
sudo curl -sSL https://microsoft.com | sudo tee /etc/apt/sources.list.d/mssql-server-2022.list

# Update tracking definitions and install the SQL Server core database engine
sudo apt-get update && sudo apt-get install -y mssql-server

002. Run the interactive setup script on each host to choose your license profile, configure an administrative password, and enable the high availability modules:

# Launch the instance setup prompts
sudo /opt/mssql/bin/mssql-conf setup

# Turn on the internal Always On high availability settings extension
sudo /opt/mssql/bin/mssql-conf set hadr.hadrenabled 1
sudo systemctl restart mssql-server

📋 Sequence 101 to 200: Generate Mirroring Endpoints & Build Availability Group

Execute cryptographic certificate scripts, copy security keys across server subnets, and link databases to the synchronization pipeline.

📁 Reference Source Files: 9_Create_Cert_Endpoint_Primary.sql | 10_Create_Cert_Endpoint_Secondary.sql | 11_Associate_Certs.sql | 12_Create_AG.sql | 13_Add_DB_to_AG.sql

101. Run this script block on the Primary Server (DB1) to provision your network authentication certificate and database mirroring endpoint:

USE master;
GO
CREATE MASTER KEY ENCRYPTION BY PASSWORD = 'SecureKeyPassword88!';
CREATE CERTIFICATE AG_Transport_Cert WITH SUBJECT = 'AG Authentication';

CREATE ENDPOINT [Hadr_endpoint] STATE = STARTED AS TCP (LISTENER_PORT = 5022)
    FOR DATABASE_MIRRORING (ROLE = ALL, AUTHENTICATION = CERTIFICATE AG_Transport_Cert, ENCRYPTION = REQUIRED ALGORITHM AES);
GO

102. After copying the exported certificate keys securely to your replicas via network copy utilities, connect to DB2 and DR-DB1 to import the profiles and initialize matching database endpoints:

USE master;
CREATE CERTIFICATE AG_Transport_Cert FROM FILE = '/var/opt/mssql/backup/agcerts/AG_Transport_Cert.cer'
WITH PRIVATE KEY (FILE = '/var/opt/mssql/backup/agcerts/AG_Transport_Cert.key', DECRYPTION BY PASSWORD = 'SecureKeyPassword88!');

CREATE ENDPOINT [Hadr_endpoint] STATE = STARTED AS TCP (LISTENER_PORT = 5022)
    FOR DATABASE_MIRRORING (ROLE = ALL, AUTHENTICATION = CERTIFICATE AG_Transport_Cert, ENCRYPTION = REQUIRED ALGORITHM AES);
GO

103. Create the Availability Group on the Primary Node (DB1), setting local configurations to synchronous commit and the remote disaster recovery node to asynchronous mode:

CREATE AVAILABILITY GROUP [ptag] WITH (CLUSTER_TYPE = EXTERNAL)
FOR REPLICA ON
    N'DB1' WITH (ENDPOINT_URL = N'TCP://192.168.1.1:5022', AVAILABILITY_MODE = SYNCHRONOUS_COMMIT, FAILOVER_MODE = EXTERNAL, SEEDING_MODE = AUTOMATIC),
    N'DB2' WITH (ENDPOINT_URL = N'TCP://192.168.1.2:5022', AVAILABILITY_MODE = SYNCHRONOUS_COMMIT, FAILOVER_MODE = EXTERNAL, SEEDING_MODE = AUTOMATIC),
    N'DR-DB1' WITH (ENDPOINT_URL = N'TCP://172.30.1.1:5022', AVAILABILITY_MODE = ASYNCHRONOUS_COMMIT, FAILOVER_MODE = EXTERNAL, SEEDING_MODE = AUTOMATIC);
GO

104. Connect to the replicas and run these database updates to join the running group and authorize automatic database file creation:

ALTER AVAILABILITY GROUP [ptag] JOIN WITH (CLUSTER_TYPE = EXTERNAL);
ALTER AVAILABILITY GROUP [ptag] GRANT CREATE ANY DATABASE;
GO

105. Add your target user workload databases to the availability cluster by running this on the Primary Node (DB1):

ALTER DATABASE [EnterpriseAppDB] SET RECOVERY FULL;
BACKUP DATABASE [EnterpriseAppDB] TO DISK = '/var/opt/mssql/backup/EnterpriseAppDB.bak';
ALTER AVAILABILITY GROUP [ptag] ADD DATABASE [EnterpriseAppDB];
GO
