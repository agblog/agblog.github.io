📦 Chapter 4: Pacemaker Cluster Tools & QDevice Corosync Sync

This chapter covers setting up your administrative cluster profiles, linking token exchange nodes, and integrating the dynamic voter.

📋 Sequence 1 to 100: Install Cluster Daemons & Align Access

Install the foundational high-availability packages and synchronize administrative engine identities across hosts.

📁 Reference Source File: 4_Install_Cluster_Tools.txt

001. Run this installation script block on all database nodes to download the core system clustering tools:

# Download the cluster stack software suites
sudo apt-get install -y pacemaker pcs corosync corosync-qdevice

002. Run this on every host to configure matching administrative passwords for the default backend cluster profile:

# Sync administrative cluster credentials across system perimeters
echo "hacluster:SecureClusterPass77!" | sudo chpass --stdin hacluster
sudo systemctl enable --now pcsd

📋 Sequence 101 to 200: Initialize Cluster Mesh & Bind QDevice Voter

Link the cluster network nodes together from the master terminal panel and integrate the dynamic network witness.

📁 Reference Source File: 5_QDevice_Corosync_Setup.sh

101. Execute this handshake sequence exclusively from the Primary Node (DB1) to authenticate the endpoints and build the operational node mesh:

# Authenticate the cluster members via the pcs interface tool
sudo pcs cluster auth DB1 DB2 DR-DB1 -u hacluster -p SecureClusterPass77!

# Form the cluster network mesh and give it a group identifier name
sudo pcs cluster setup sqlcluster DB1 DB2 DR-DB1 --force

# Launch the cluster service processes across all network environments
sudo pcs cluster start --all
sudo pcs cluster enable --all

102. Connect your cluster to the neutral witness server by mapping the external QDevice network connection over port 5403:

# Hardening: Disable hardware node fencing restrictions for virtualization setups
sudo pcs property set stonith-enabled=false

# Add the neutral voter to the cluster topology using the Linear Minimum Split (LMS) rule
sudo pcs cluster qdevice add net --peer-ids=20.20.20.178 --algo=lms

103. Run a check on the active configuration tracking layouts to make sure tokens are passing smoothly:

sudo pcs status
corosync-cmapctl | grep qdevice
