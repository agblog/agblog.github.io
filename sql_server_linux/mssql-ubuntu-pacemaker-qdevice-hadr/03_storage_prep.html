🗄️ Chapter 3: LVM Storage Volume Setup & Partition Mounting

This chapter walks you through isolating database directory trees to separate random data disk reads from sequential database logging activities.

📋 Sequence 1 to 100: Physical Volume Provisioning

Perform these baseline commands to format raw unpartitioned space into flexible LVM logical storage tracks.

📁 Reference Source File: 3_Disk_Preparations.sh

001. Run these commands on all database nodes to identify your raw disks and build the LVM physical baseline storage pools:

# Scan the host to discover newly attached physical storage disks
sudo lsblk

# Initialize the raw disk (e.g., /dev/sdb) as an LVM Physical Volume
sudo pvcreate /dev/sdb

# Create a primary Volume Group named vg_mssql to hold your database structures
sudo vgcreate vg_mssql /dev/sdb

📋 Sequence 101 to 200: Logical Volume Separation & File Mounts

Carve out isolated logical tracks, format them with XFS filesystems, and apply secure directory paths.

101. Allocate explicit logical disks out of your volume group to isolate data, transaction logs, and temporary work drives:

# Carve out folders for database data files, transaction logs, and tempdb tracking
sudo lvcreate -L 40G -n lv_sqldata vg_mssql
sudo lvcreate -L 20G -n lv_sqllog vg_mssql
sudo lvcreate -L 10G -n lv_sqltemp vg_mssql

102. Format the partitions using high-throughput XFS filesystems and create matching system destination mount directories:

# Form new block groups across layouts
sudo mkfs.xfs /dev/vg_mssql/lv_sqldata
sudo mkfs.xfs /dev/vg_mssql/lv_sqllog
sudo mkfs.xfs /dev/vg_mssql/lv_sqltemp

# Build segregated system directory trees
sudo mkdir -p /var/opt/mssql/data
sudo mkdir -p /var/opt/mssql/log
sudo mkdir -p /var/opt/mssql/tempdb
sudo mkdir -p /var/opt/mssql/backup/agcerts

103. Mount the logical drives immediately to connect your persistent volumes to the running operating system file tree:

sudo mount /dev/vg_mssql/lv_sqldata /var/opt/mssql/data
sudo mount /dev/vg_mssql/lv_sqllog /var/opt/mssql/log
sudo mount /dev/vg_mssql/lv_sqltemp /var/opt/mssql/tempdb
